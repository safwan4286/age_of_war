# Music

Drop MP3 loops here with exactly these names; missing files just mean silence.

| File | Plays |
|---|---|
| `menu.mp3` | Menu, difficulty and settings screens |
| `battle_stone.mp3` | Battle while you're in the Stone Age |
| `battle_medieval.mp3` | Battle after you evolve to the Medieval Age |

Victory and defeat jingles are sound effects (`assets/audio/sfx/victory.wav`, `defeat.wav`).
Loops should start and end cleanly (no fade), 1–3 minutes, about -14 LUFS, 128–192 kbps.
